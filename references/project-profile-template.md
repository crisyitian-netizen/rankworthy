# Project profile template

Save one per website (as a file in the project, or as its own skill named `<company>-seo`). Rankworthy reads it at the start of every task; its rules override the general skill.

```markdown
# <Company> SEO / GEO profile

## Language
- Owner reports: <language>
- Site content: <language-REGION>
- Languages that must never appear in indexable places: <...>

## Rules
1. Backups: <where>; approval before going live: <who>
2. Private data never public: <wholesale prices, SKUs, stock...>
3. Do not contact customers without approval
4. <other>

## Facts (keep identical everywhere)
- Site / brand name / Business Profile name:
- What we sell, to whom, where:
- Shipping time / couriers / minimum order / payment:
- Contact:

## Money pages and target keywords
| Page | Main keyword | Intent | Notes |

## Competitors
| Domain | Strengths | Where they are weak |

## Baselines (date, definition)
| Metric | Date | Value |
AI prompt set (fixed): <list>

## Running automation
| Task | Frequency | What it does |

## Open tasks
| # | Task | Owner | Status |

## Change log
| Date | Change | Why | Re-check | Verdict |
```
